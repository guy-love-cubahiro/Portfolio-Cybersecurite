# Projet 01 – Wireshark

## Objectif

Ce projet a pour objectif d'apprendre à capturer, analyser et interpréter le trafic réseau à l'aide de Wireshark.

Les captures sont réalisées dans un laboratoire personnel composé de plusieurs machines virtuelles sous VMware Workstation.

## Environnement du laboratoire

- Hôte : Windows 11
- Hyperviseur : VMware Workstation Pro
- Machines virtuelles :
  - Windows 11
  - Windows Server 2022
  - Kali Linux

## Outils utilisés

- Wireshark
- Git
- GitHub
- GitHub Desktop

## Laboratoires prévus

- Capture ICMP (Ping)
- Analyse ARP
- Analyse DNS
- Analyse TCP
- Analyse HTTP
- Analyse HTTPS/TLS
- Analyse des scans Nmap

## Compétences développées

- Capture de trafic réseau
- Analyse des protocoles réseau
- Résolution de problèmes réseau
- Documentation technique
- Gestion de projet avec Git et GitHub
