# Chapitre 7 - Méthodologie d'un audit Nmap

## Les étapes d'un audit

1. Vérifier que la cible est joignable.
2. Identifier les ports ouverts.
3. Identifier les services et leurs versions.
4. Détecter le système d'exploitation.
5. Utiliser les scripts NSE adaptés aux services détectés.
6. Rechercher les vulnérabilités.

## Conclusion

Un audit professionnel progresse du moins intrusif vers le plus intrusif. Chaque étape fournit des informations qui permettent de choisir la suivante.
