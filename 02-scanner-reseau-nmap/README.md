# Projet 02 – Scanner de réseau avec Nmap

## Présentation

Ce projet présente un laboratoire de découverte et d'analyse réseau réalisé avec Nmap dans un environnement virtuel contrôlé.

L'objectif est d'apprendre à identifier les hôtes actifs, analyser les ports ouverts, détecter les services et interpréter les résultats dans une démarche professionnelle de cybersécurité.

## Objectifs

- Découvrir les hôtes actifs sur un réseau.
- Identifier les ports ouverts.
- Détecter les services et leurs versions.
- Estimer le système d'exploitation des machines.
- Exporter et analyser les résultats.
- Produire une documentation complète du laboratoire.

## Environnement du laboratoire

- Kali Linux
- Windows 11
- Windows Server 2022
- VMware Workstation Pro 17
- Nmap

## Structure du projet

- Documentation
- Captures d'écran
- Résultats des analyses
- Ressources

## Compétences développées

- Découverte des hôtes avec Nmap
- Analyse des ports TCP et UDP
- Détection des services et de leurs versions
- Estimation du système d'exploitation
- Utilisation des scripts NSE
- Interprétation des états des ports (open, closed, filtered)
- Analyse des résultats
- Rédaction d'un rapport d'audit professionnel

## Documentation disponible

- Documentation complète du laboratoire
- Rapport d'audit réseau
- Captures d'écran

## Connaissances acquises

Au cours de ce projet, j'ai appris à :

- choisir la méthode de scan adaptée ;
- interpréter les résultats sans tirer de conclusions hâtives ;
- comprendre les limites des outils de scan ;
- appliquer une méthodologie professionnelle d'audit réseau.
